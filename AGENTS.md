# Instruções do projeto

- Comente em português cada linha executável de código novo ou alterado, colocando uma explicação adjacente que descreva seu efeito ou finalidade.
- Preserve as explicações existentes quando editar código; atualize o comentário quando mudar o comportamento da linha.
- Para CSS embutido em strings Python, use comentários CSS (`/* ... */`) sem alterar os seletores, valores ou o conteúdo das strings HTML.
- Não insira comentários em linhas de dados, textos exibidos ao usuário, exemplos, strings HTML ou linhas em branco.
- Comentários devem explicar o comportamento, e não apenas repetir literalmente a instrução.
